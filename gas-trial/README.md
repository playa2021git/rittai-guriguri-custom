# GAS許可設定（試験・本番共通）

対象プロジェクト：利用者が作成したGoogle Apps Script。`Code.gs` は1ファイルで動作し、追加のHTMLファイル、スプレッドシート、APIキー、課金設定は不要です。

## 1. コードを貼り付ける

1. `Code.gs` の内容を全文コピーします。
2. GASの「コード.gs」の初期コードを全文置き換えます。
3. Ctrl＋Sで保存します。プロジェクト名は「立体グリグリ GAS試験」などにします。
4. 上の関数選択で `setupTeacher` を選び、実行します。

作成者本人のアカウントで実行してください。Googleの権限確認が出た場合は表示内容を確認します。このコードはメールアドレスの照合とスクリプト内の設定保存を使います。メール本文やGoogleドライブ内のファイルは読みません。承認警告が不明な場合は、その画面を確認してから進めてください。

## 2. ウェブアプリとしてデプロイする

1. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」。
2. 次のユーザーとして実行：自分。
3. アクセスできるユーザー：全員（ログインなしの読み取り試験をする場合）。学校・組織の設定によって選べないことがあります。
4. 公開された `/exec` で終わるURLを控えます。

全員へ公開するのは、教材IDの読み取りと試験ページです。サーバー側の書き込み関数は、`setupTeacher` を実行したアカウントのメールアドレスと訪問者を毎回照合します。実行者の権限を表す `getEffectiveUser()` だけで訪問者を判定しない設計です。本人確認ができない場合は書き込みを拒否します。

## 3. 先生と生徒の2画面で試す

- 先生：`/exec` または `/exec?mode=teacher`。プロジェクトを作成したGoogleアカウントで開きます。
- 生徒側の確認：先生画面の「生徒側の確認画面を別タブで開く」。別端末でも同じURLを開けます。
- 読み取りJSON：`/exec?mode=api`。
- 将来のGitHub連携用JSONP：`/exec?mode=api&callback=任意の安全な関数名`。公開してよい教材IDのみ返します。

生徒側を先に開き、先生側でチェックを変えて「許可を反映」を押します。生徒側は約5秒ごとに読み込み、リストの変化を表示します。表示する時間はGoogleの保存時刻と生徒端末の受信時刻の差で、端末時計のずれを含む参考値です。

## 制限

試験で動作確認後、GitHub教材から同じ読み取り専用APIへ接続します。ChatGPT Sitesとは別の保存先です。無料枠の上限をなくす仕組みではありません。

Script Propertiesの読み取りを減らすため、30秒の共有キャッシュを使います。先生が保存すると同時にキャッシュも更新し、古い内容が30秒残らないようにしています。設定更新は排他制御し、古い先生画面からの上書きを防ぎます。

Googleアカウントの識別情報が取得できない場合、先生画面は開けません。複数アカウントでのログインを避け、作成者のアカウントで開いて確認します。所有者照合は無効化しないでください。

ローカル確認：`node tests/verify-gas-trial.cjs`。実際のGASへの貼り付け・公開・権限承認・実機確認は別途必要です。

## 既に試験版を公開した場合の更新

1. `Code.gs` の全文で、GASエディタのコードを置き換えて保存。
2. 「デプロイ」→「デプロイを管理」。
3. 現在のウェブアプリを選び、鉛筆マークで編集。
4. バージョンで「新しいバージョン」を選んでデプロイ。

この操作なら既存の `/exec` URLを維持できます。`setupTeacher` の再実行は不要です。先生の登録と許可設定はScript Propertiesに保存されているため保持されます。「新しいデプロイ」を作るとURLが変わるため、既存デプロイを更新してください。
