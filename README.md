## 原作者への謝辞と、この版の変更点

川俣純先生、長年にわたり「立体グリグリ」を開発・公開し、改変して授業に活用できる形で共有してくださり、ありがとうございます。立体を動かしながら等角図と正投影図の関係を学べる原作を土台に、生徒がChromebookで寸法を読み取り、紙に作図する授業に合わせてこの版を作りました。

このリポジトリは原作を改変した派生版です。原作の開発者は川俣純先生であり、以下は本版で追加・変更した内容です。

- Chromebookでピンチ操作が難しい生徒にも使える拡大・縮小ボタンと、統一した初期表示サイズ。
- 5mm／10mmの色分け点線目盛りと、mm単位の寸法線。三面図だけ・等角図だけ・両方への表示切り替えとPNG出力への反映。
- 授業用GRI教材8個を紹介順に内蔵し、紙への作図に合わせて寸法を調整。起動時は1辺20mmの立方体を表示。
- 問題ごとに等角図・三面図の答え側を隠す表示制限と、先生用の解除操作。
- 追加した全教材に面データを付け、面色と隠れ線の表示切り替えに対応。初期状態は面色あり・隠れ線なし。
- ゲームコントローラーの操作案内・状態表示を非表示にし、読み取りを停止。

原作者の表示、原作へのリンク、およびCC BY 4.0のライセンスを継承しています。原作のREADMEは下部に参考資料として残しています。

## Chromebook向け作図学習版

`index.html` をChromeで開いて使います。最初は「立方体（1辺20mm）」の等角図で起動し、立体が表示エリアの高さの約半分に収まる大きさで表示します。4面表示へ自由に切り替えられます。

- 左の「作図学習」で、青い5mm・橙の10mmの点線目盛りをオン／オフできます。10mmの位置には橙を使います。
- 寸法線は「表示しない／三面図のみ／等角図のみ／両方表示」から選択できます。端点記号、寸法補助線、mm単位の寸法値を表示します。
- 全体寸法と、座標方向の段差の区間寸法を自動表示します。複雑な形状（軸ごとの座標が9個以上）は全体寸法を優先し、狭い区間は省略します。斜辺長・円の直径・穴の寸法を自動指定する機能ではありません。
- 図の表示エリア左下で「かくれ線」「面の色」の横にある「− 縮小／＋ 拡大」で、ピンチ操作なしで拡大縮小できます。授業用の出題中も使えます。
- 「三面図＋等角図にそろえる」で基本表示に戻れます。ドラッグで回転、トラックパッドのスクロールやピンチで拡大縮小します。
- すべての授業用教材とSTLは、読み込み時に面色を表示します。面色ボタンでオフにもできます。
- PNG出力にも現在の点線目盛りと寸法表示設定を反映します。
- DualShock／ゲームパッドの案内と状態表示は非表示にし、毎フレームのゲームパッド読み取りを停止しています。

寸法は元データの座標から計算します。GRI／STLの1単位を1mmとして扱います（STL自体には単位情報がありません）。ズームしても寸法値は変わりません。画面上の表示は実寸ではないため、画面に定規を当てず、目盛りと数値を使って紙に作図してください。大きなモデルで点線間隔が細かすぎる場合は目盛りを省略します。

変更: Chromebookでの作図学習に合わせたUI・目盛り・寸法線を追加。原作者の表示とCC BY 4.0のライセンスは維持しています。英語版HTMLと以下の原作者READMEは原作の参考資料です。

面データを再構築する保守スクリプト: `python scripts/prepare-lesson-surfaces.py`（閉じた面の接続を検証します。サイズは変更しません）。

開発時の確認: `node tests/verify-measurements.cjs`。描画APIを模擬して寸法値・投影別表示・目盛り・PNG描画・原作の自己テストを確認します。Chromebook実機でのタッチ操作や描画速度は別途確認してください。

## 授業用の問題選択

左上の「授業用」で次の8つの問題を選べます。元ファイルは `lessons/` に保存し、HTMLにも問題データを内蔵しているので、`index.html` 単体で使えます。

授業の紹介順に、次の順序で並びます。最後に自由練習があります。

| 問題 | 生徒に見せる図 |
| --- | --- |
| 立方体（1辺20mm） | 起動時に表示。等角図で開始、4面切り替え可 |
| 等角図点つなぎ 立方体＋滑り台のお手本 | 等角図で開始、4面切り替え可 |
| 等角図プリント③ 台の上に小さな立方体 | 等角図で開始、4面切り替え可 |
| 等角図プリント④ 凹 | 等角図で開始、4面切り替え可 |
| 等角図を見て正投影図に① | 等角図のみ |
| 等角図を見て正投影図に② | 等角図のみ |
| 正投影図から等角図へ① | 三面図のみ |
| 正投影図から等角図へ② | 三面図のみ |
| 自由練習 | 別の立体に切り替え、表示制限なし |

表示が制限された問題の出題中は視点変更、回転、描画、立体の保存・変換・差し替えを制限します。寸法線、点線目盛り、拡大縮小、PNG出力は使えます。PNGにも許可された図だけを出力します。「自由練習」に戻ると別の練習用立体に切り替わり、問題の答えは引き継ぎません。

先生用の隠し操作は **Ctrl＋T** です。Ctrl＋TはChromeの「新しいタブ」と競合し、Webページが受け取れない場合があります。その場合は **「授業用」の見出しをダブルクリック** して同じ解除／再制限を行ってください。Ctrl＋Tを受け取れた場合は、押すと両方の図を表示でき、もう一度押すと元の問題に戻って再制限します（先生確認中に立体を変更していても元の問題を復元します）。問題を選び直したときも解除状態は引き継ぎません。キー操作の案内は生徒用の画面には表示しません。これは教室での表示制御であり、ログイン認証ではありません。

追加した8つのGRI教材すべてに閉じた面データを内蔵し、隠れ線の表示／非表示（Kキー）と面色（Sキー）に対応しています。初期表示は隠れ線なし・面色ありです。追加済み教材と同じ線分データをGRIファイルから直接読み込んだ場合も面データを適用します。任意の未登録GRIの面を自動推定する機能ではありません。

「正投影図から等角図へ①」は元の比率を保って最大40mm（幅・高さ・奥行とも40mm）に縮小しています。

「正投影図から等角図へ②」は幅60×高さ40×奥行40mmです。幅方向の区間は20mm刻み、高さの段差も20mm刻みです。三面図だけを見せる出題制限は維持しています。

③は20×10×20mmの土台に、10×10×10mmの立方体を載せた形です。④は幅30×高さ20×奥行10mm、凹みの幅・深さ10mmです。③・④・立方体・点つなぎは4面表示への切り替えを制限しません。ほかの4問の出題制限は維持します。

「点つなぎプリント2個目」は30×20×20mmに縮小しています（立方体部分の1辺20mm、全体の長い辺30mm）。滑り台部分は同じ比率を保つため、10mmの区間や約28.28mmの斜辺もあります。この教材は等角図で開始し、通常の1面／4面切り替えが使えます。面情報を追加し、画面左下の隠れ線ボタン（Kキー）と面色ボタン（Sキー）も使えます。初期表示は隠れ線なし・面色ありです。

追加の「立方体」は元データの1辺40mmを半分にし、全12辺が20mmとなるデータを保存・内蔵しています。元の指定ファイルは変更していません。

元のGRIは旧版の「幅・高さ・奥行き・辺数」ヘッダーで、末尾に作成情報があります。指定された外部の原本は変更していません。サイズ変更した教材は `lessons/` の配布用データと内蔵データの両方に反映しています。ヘッダーはWeb版の形式へ変換し、末尾の作成情報は内蔵データに含めません。

# 立体グリグリ Vibe-Coded V1

**立体グリグリ** は、第三角法による正投影図の学習を支援するためのシンプルなWebアプリです。

中学校技術科の製図学習、空間認識、立体の見方の指導などで使うことを想定しています。

## 概要

立体グリグリは、立体をグリグリと動かしながら、平面図・正面図・右側面図・等角図の関係を確認できる教材アプリです。

もともとはワイヤーフレーム表示の教材でしたが、このWeb版ではSTLファイルの読み込みにも対応しました。Tinkercadなどで作成した簡単な立体をSTL形式で書き出し、立体グリグリで表示することができます。

ただし、このアプリ自体でSTLファイルを作成することはできません。STLファイルの作成は、Tinkercadなどの3Dモデリングツールを利用してください。

## 主な機能

* 第三角法による正投影図の学習
* 平面図・正面図・右側面図・等角図の表示
* 4面表示と1面表示の切り替え
* 立体の回転・拡大縮小
* かくれ線表示の切り替え
* 面の色表示の切り替え
* 線の太さの変更
* 内蔵STLモデルの読み込み
* STLファイルの読み込み
* `.gri` ファイルの読み込み・保存
* `.gri` 形式による簡易的なワイヤーフレーム作図
* 表示中の図のPNG出力
* マウス・キーボード・タブレット操作に対応
* DualShock 4などのゲームコントローラー操作に対応

## 授業での使い方

### 1. iPadで使う

ネットにつながったiPadで公開ページをSafariで開き、「ホーム画面に追加」することで、インストールしたアプリのように使うことができます。

タブレットでは、指で立体を動かしたり、ピンチ操作で拡大縮小したりできます。生徒が自分の手元で立体を動かしながら、見取り図と三面図の関係を考える活動に向いています。

### 2. 電子黒板で使う

Windows、Mac、iPadなどで立体グリグリを開き、画面を電子黒板に投影して使うことができます。

DualShock 4などのゲームコントローラーを接続すれば、教師が教室内でコントローラーを持ちながら立体を操作できます。生徒から「この向きがわからない」と言われたときに、その場で立体を回転させながら説明できます。

これはかなり授業向きです。マウスでカチカチ操作するより、教師がコントローラーを持って立体を回す方が、教室では自然に見えます。ちょっとゲームっぽいですが、そこが強みです。

### 3. 自作STLを読み込む

Tinkercadなどで作成した簡単な立体をSTL形式で保存し、立体グリグリに読み込ませることができます。

授業者が見せたい立体を自作し、正投影図の学習に利用できます。データ量の大きいSTLファイルや複雑すぎるモデルは、読み込みに時間がかかったり、表示できなかったりする場合があります。

### 4. `.gri` 形式で作図する

`.gri` 描画モードでは、簡単なワイヤーフレーム立体を作図できます。
X・Y・Z方向にポインタを移動しながら、始点と終点を指定して線分を追加します。

作成したデータは `.gri` ファイルとして保存できます。

### キーボード操作

* 自由視点でドラッグ：立体を回転
* ホイール：拡大縮小

* ピンチ：拡大縮小
* 自由視点上でスワイプ：立体を回転
* 3本指で上下：線の太さを変更
