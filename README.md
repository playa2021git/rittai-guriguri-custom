# 立体グリグリ Vibe-Coded V1

**立体グリグリ** は、第三角法による正投影図の学習を支援するためのシンプルなWebアプリです。
1996年頃にMS-DOS上で動作するアプリケーションとして開発した「立体グリグリ」を、約30年後の2026年5月に、ChatGPT 5.5とのバイブコーディングによってWebアプリとして再構成しました。

中学校技術科の製図学習、空間認識、立体の見方の指導などで使うことを想定しています。

## 概要

立体グリグリは、立体をグリグリと動かしながら、平面図・正面図・右側面図・等角図の関係を確認できる教材アプリです。

もともとはワイヤーフレーム表示の教材でしたが、このWeb版ではSTLファイルの読み込みにも対応しました。Tinkercadなどで作成した簡単な立体をSTL形式で書き出し、立体グリグリで表示することができます。

ただし、このアプリ自体でSTLファイルを作成することはできません。STLファイルの作成は、Tinkercadなどの3Dモデリングツールを利用してください。

## 主な機能

* 第三角法による正投影図の学習
* 平面図・正面図・右側面図・等角図の表示
* 4面表示と1面表示の切り替え
* 立体の回転・拡大縮小
* かくれ線表示の切り替え
* 面の色表示の切り替え
* 線の太さの変更
* 内蔵STLモデルの読み込み
* STLファイルの読み込み
* `.gri` ファイルの読み込み・保存
* `.gri` 形式による簡易的なワイヤーフレーム作図
* 表示中の図のPNG出力
* マウス・キーボード・タブレット操作に対応
* DualShock 4などのゲームコントローラー操作に対応

## 授業での使い方

### 1. iPadで使う

ネットにつながったiPadで公開ページをSafariで開き、「ホーム画面に追加」することで、インストールしたアプリのように使うことができます。

タブレットでは、指で立体を動かしたり、ピンチ操作で拡大縮小したりできます。生徒が自分の手元で立体を動かしながら、見取り図と三面図の関係を考える活動に向いています。

### 2. 電子黒板で使う

Windows、Mac、iPadなどで立体グリグリを開き、画面を電子黒板に投影して使うことができます。

DualShock 4などのゲームコントローラーを接続すれば、教師が教室内でコントローラーを持ちながら立体を操作できます。生徒から「この向きがわからない」と言われたときに、その場で立体を回転させながら説明できます。

これはかなり授業向きです。マウスでカチカチ操作するより、教師がコントローラーを持って立体を回す方が、教室では自然に見えます。ちょっとゲームっぽいですが、そこが強みです。

### 3. 自作STLを読み込む

Tinkercadなどで作成した簡単な立体をSTL形式で保存し、立体グリグリに読み込ませることができます。

授業者が見せたい立体を自作し、正投影図の学習に利用できます。データ量の大きいSTLファイルや複雑すぎるモデルは、読み込みに時間がかかったり、表示できなかったりする場合があります。

### 4. `.gri` 形式で作図する

`.gri` 描画モードでは、簡単なワイヤーフレーム立体を作図できます。
X・Y・Z方向にポインタを移動しながら、始点と終点を指定して線分を追加します。

作成したデータは `.gri` ファイルとして保存できます。

## 基本操作

### キーボード操作

| キー  | 機能                 |
| --- | ------------------ |
| `1` | 正面図                |
| `2` | 右側面図               |
| `3` | 平面図                |
| `4` | 等角図                |
| `D` | `.gri` 描画          |
| `F` | 立体を読み込む（GRI / STL） |
| `H` | 立体を保存する（GRI）       |
| `M` | ワイヤーフレームにする        |
| `P` | 図をPNG出力            |
| `B` | クリック音の消音           |
| `N` | 立体データを消去           |
| `+` | 線を太くする             |
| `-` | 線を細くする             |
| `K` | かくれ線表示の切り替え        |
| `S` | 面の色表示の切り替え         |

### マウス操作

* 自由視点でドラッグ：立体を回転
* ホイール：拡大縮小
* 4面モードの各ラベルをクリック：1面表示に切り替え

### タブレット操作

* ピンチ：拡大縮小
* 自由視点上でスワイプ：立体を回転
* 3本指で上下：線の太さを変更

### DualShock 4操作

| 操作       | 機能             |
| -------- | -------------- |
| 左スティック上下 | 拡大縮小           |
| 右スティック   | 視点移動           |
| □        | 正面図            |
| ○        | 右側面図           |
| △        | 平面図            |
| ×        | 等角図            |
| 方向キー上下   | 緯度方向に回転        |
| 方向キー左右   | 経度方向に回転        |
| R1       | かくれ線表示の切り替え    |
| R2       | 面の色表示の切り替え     |
| L1       | 操作説明の表示・非表示    |
| SHARE    | 4面表示／1面表示の切り替え |
| OPTIONS  | 内蔵STL選択        |

## ローカルで使う方法

このリポジトリをダウンロードすれば、インターネットに接続しなくてもローカル環境で利用できます。

## 開発の背景

立体グリグリは、第三角法による正投影図の学習を支援するために、1996年頃にMS-DOS上で動作する教材として開発しました。
画面上の立体を動かしながら、平面図・正面図・右側面図の関係を学ぶこと自体が大きな意味を持つことは、当時から全く変わっていません。

2026年、この教材をWebアプリとして再構成しました。
HTMLファイルを中心としたシンプルな構成にすることで、授業者自身が必要に応じて改変しやすいようにしています。

このWeb版は、ChatGPT 5.5とのバイブコーディングによって制作しました。
授業をつくるように、教材アプリもその場で考え、試し、直していく。そうした教材開発の可能性を示す試みでもあります。
