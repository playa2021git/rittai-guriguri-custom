Game Controller Controls
You can control this app with a DualShock 4 over Bluetooth!
←/→: Horizontal rotation
↑/↓: Vertical rotation
Shift+↑/↓: Zoom in/out
K: Toggle hidden lines
S: Toggle surface colors
Mouse: For GRI, left-drag in the Free View to rotate. For STL, left-drag on the model to rotate. Use the wheel anywhere to zoom.
“Built-in STL” at the bottom right: Choose and load a built-in STL model.
Tablet: Pinch to zoom / swipe on the Free View to rotate.
Tablet: Swipe up/down with three fingers to change line width.
In 4-view mode, click/tap each label to switch to a single view.
.gri Drawing Controls
BS：Delete the last edge drawn
Shift+BS：Restore the edge most recently deleted
X/Y/Z：Move the pointer in the positive direction of each axis
Shift+X/Y/Z：Move the pointer in the negative direction of each axis
O：Move the pointer back to the origin
Drawing buttons at the upper right: use ‹ X -X ›, ‹ Y -Y ›, ‹ Z -Z ›, Origin, Eraser, OK, and Step. Coordinates are shown next to the pointer.
Enter：Set the start point / add an edge as the end point
Delete：Delete the selected red segment / delete or split edges overlapping the range from start to end
In Free View, move the mouse near an edge: it highlights in red.
Right-click the highlighted edge: confirm and delete it.
Esc：Cancel the start/end point selection

“3D Guriguri” was originally developed by Jun Kawamata around 1996 as an MS-DOS application for learning orthographic projection using the third-angle method. This version was created 30 years later, in May 2026, through vibe coding together with ChatGPT 5.5. It is released under CC BY, so you may freely modify and use it at your own discretion.

This version can load STL files. It cannot create STL files, so please create STL files with tools such as Tinkercad and load them here. Hidden-line display is also mostly supported.
